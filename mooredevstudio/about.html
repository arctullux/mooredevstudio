About Me

Hi! I am Alex Moore, the sole developer and manager behind Moore Dev Studio.

I have a deep interest in software development. I was a gamer growing up, and I eventually shifted towards light game development on a platform called Roblox. It was then until I realized I can build some pretty cool stuff with computers.

Fast-forward a few years after high school, now I am building websites. I found out that websites are another cool thing that I could make, they are more important to a business than some people realize, and they're also easy and fun to develop.

In the position that I am in, I figured that I would help other individuals and smaller organizations set up and run their websites.

Technologies I Use

You may be wondering how I actually make websites. Websites are structured and formatted like a Microsoft Word document, but it's a little more advanced than that.

* HTML

- I use HTML to write the bare-bones structure for a website.

* CSS

- I use CSS to format and style the website, giving it a full UI layout, aswell as light functionality and animations.

* JavaScript

- Like HTML and CSS, JavaScript is the standard programming language for the web. It allows full front-end functionality for the website, and can be used for processing data on the back-end aswell. JavaScript also has applications outside the web browser.

* Browser Sync

- Browser Sync is an open source program that I run from my development environment that allows access to the website in progress to other devices on my home network. I will typically have the website open on a computer, phone, or sometimes a tablet to ensure responsiveness during development. It will also update in real time, and is vital to my workflow.

* Cloudflare Pages

- For simple static websites that do not require database integrations or a functionality of Cloudflare Workers, Cloudflare Pages is what I use to host a website in a serverless environment. At this stage in the process, it will be associated with a registered custom domain and published to the web.
